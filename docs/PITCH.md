## 200 words

HTTP 402 AI Tollbooth is a working pay-per-request data service for developers and AI agents. It offers 203 troubleshooting products across DevOps, APIs, ML/AI, web frontend, and databases. Every product has a free three-record preview, so humans and crawlers can inspect the schema and quality before paying.

The paid flow uses the web’s native `402 Payment Required` status and Bitcoin Lightning. A request receives a BOLT11 invoice; after payment, the client retries with the payment hash and preimage to unlock the complete dataset. Entry, Standard, and Premium tiers return 50, 100, and 200 records for 2,000, 5,000, and 10,000 sats. There are no accounts, subscriptions, credit cards, or API keys.

The service is designed for machine discovery. It publishes OpenAPI 3.1, MCP and AI-plugin manifests, `llms.txt`, `llms-full.txt`, `robots.txt`, and a complete sitemap. Each record has a stable error code, a plain-language description, and a programmatic fix. Runtime generation uses an AI provider when available and a deterministic, topic-specific fallback when it is not. Durable Objects protect counters and one-time redemption against races. The complete Lightning purchase and 50-item redemption flow has been verified on the live Worker.
